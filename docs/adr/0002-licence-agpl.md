# 0002 - Licence: AGPL-3.0

Date: 2026-11-23. Status: accepted. Replaces the Apache-2.0 licence from the initial commit.

## Context

Noon Gun ships both as a self-hosted tool and, later, as a hosted service. The
brief (section 13.2) weighed AGPL-3.0 against MIT.

## Decision

License the project under AGPL-3.0.

## Consequences

- Anyone offering a modified Noon Gun as a hosted service must publish their changes.
- Ideas and code from Postiz (AGPL-3.0) may be used, with attribution.
- Mixpost Lite (MIT) code may still be reused with attribution.
- Mixpost Pro and Enterprise remain off limits.
- Contributions are accepted under AGPL-3.0. Dual licensing for the hosted
  edition would need a contributor agreement; not needed now.
